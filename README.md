# QuickHeatFix

Programmatic SEO Next.js site for `quickheatfix.com`.

## Data Source
- Spreadsheet input: `Water Heater pSEO - quickheatfix.com .xlsx`
- Generated page dataset: `lib/waterheater-data.ts` (246 pages)

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS v4

## Main Routes
- Home: `app/page.tsx`
- Service index: `app/services/page.tsx`
- Dynamic pages: `app/[slug]/page.tsx`
